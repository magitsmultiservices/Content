# Content Magits Multiservices

Scripts en ideeën voor video's op sociale media.

- `CLAUDE.md`: bedrijfsinfo en schrijfregels (Claude leest dit automatisch)
- `scripts/ondernemen/`: video's over ondernemen
- `scripts/klanten/`: video's om klanten te bereiken
- `sjablonen/`: vaste opbouw voor een nieuw script
- `ideeen.md`: lijst met video-ideeën
